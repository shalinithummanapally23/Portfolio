## 🚀 Local Development

```bash
# Navigate into directory
cd a:\Shalini\Portfoilo

# Install dependencies (if not already installed)
npm install

# Run Vite dev server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
